## 1. 生活小现象引入（AI补充）

想想两件事：

- **照着菜谱做菜**：先切菜，再热油，再下锅。顺序不能乱，前一步没做完，后一步就没法开始。
- **家里的开关和灯**：开关一按，灯立刻亮。客厅、卧室、厨房的灯各接各的线，谁也不用等谁，**全部同时在工作**。只要开关的状态不变，灯的状态就一直保持。

## 2. 现象背后的逻辑

菜谱是一串**步骤**，有先后顺序，做完就结束了。

开关和灯是一套**连线**。电路做好以后就一直存在，输入一变，输出马上跟着变，也不存在「运行完了」这回事。

## 3. 引入课程内容

- **C 语言就像菜谱**：CPU 一条一条地执行语句。
- **Verilog 就像开关和灯的布线图**：你写下的每一条语句都会变成一块真实的电路，所有电路**同时**工作。

课程原文（intro §1）说：HDL「与其说是在写代码，更像是在画电路」，并且「同一时刻**并行**执行多条代码，这和 C 语言串行执行的特征存在本质上的不同」。

> [!tip] 本课最重要的一句话
> 写 Verilog 时，每写一行，都问自己：**「这一行对应电路里的什么东西？」**

## 4. 正式解释（边做边讲）

### 片段 A：模块 = 一个有引脚的黑盒

[[模块]]是 Verilog 的基本单元，可以把它想成一块芯片：外面有引脚（[[端口]]），里面是电路。

```verilog
module user_module(          // module 模块名(
    input  wire [7:0] in_data,   //   输入引脚：8 根线
    output reg  [7:0] out_data   //   输出引脚：8 根线
);                           // ← 这里的分号别漏
    // 这里写内部电路
endmodule                    // 结束
```

和 C 函数对比一下：

| C 函数 | Verilog 模块 |
| --- | --- |
| `int f(int a, int b)` | `module f(input a, input b, output y);` |
| 参数和返回值 | `input` / `output` 端口 |
| 调用一次，跑完就结束 | **一直存在，一直在工作** |

> [!example] 动手 A（2 分钟）
> 写出一个模块的**外壳**（先不写内部）：模块名 `and_gate`，有两个 1 bit 输入 `a`、`b`，一个 1 bit 输出 `y`。
> 提示：不写位宽，默认就是 1 bit。
>
> > [!success]- 参考答案（先自己写，再点开）
> > ```verilog
> > module and_gate(
> >     input  wire a,
> >     input  wire b,
> >     output wire y
> > );
> > endmodule
> > ```

### 片段 B：位宽、向量与数值表示

在硬件里，一个 8 bit 数就是 **8 根并排的导线**，每根线上是 0 或 1。

- `wire [7:0] x;` 表示 8 根线，编号从 7（最高位）到 0（最低位）。这种多位的信号叫[[位宽与向量|向量]]。
- 不写 `[..]` 时就是 1 根线，叫标量。

常数要写成 `位宽'进制数值` 的形式（[[数值表示]]）：

| 写法 | 含义 |
| --- | --- |
| `8'b0011_0011` | 8 位二进制，下划线只是为了好读 |
| `4'hA` | 4 位十六进制 A，也就是 `4'b1010` |
| `8'd15` | 8 位十进制 15 |
| `1'b1` | 1 位的 1 |

除了 0 和 1，电平还可能是 **x**（未知）或 **z**（高阻，可以理解为线悬空、没有接任何驱动）。仿真时看到 x 或 z，通常说明有信号没接或者没赋值。

> [!example] 动手 B（1 分钟）
> 1. `4'hC` 写成二进制是多少？
> 2. `8'b1010_0101` 写成十六进制是多少？
>
> > [!success]- 答案
> > 1. `4'b1100`　2. `8'hA5`

### 片段 C：wire 和 reg，先记一条规则就够

C 语言里有 int、char 等很多类型，Verilog 主要只有两种：[[wire与reg]]。

| | wire | reg |
| --- | --- | --- |
| 本质 | 一根导线 | 「在 always 里被赋值的信号」 |
| 在哪里赋值 | `assign` | `always` |
| 是寄存器吗 | 不是 | **不一定！** 名字有误导性 |

> [!warning] 新手第一大坑
> `reg` **不等于**寄存器，也不等于 C 里的变量。在组合逻辑的 always 里，reg 综合出来就是一根线（verilog1 §1.1.3 原文：「reg 关键字只是声明了一个在 always 语句中进行赋值的信号」）。

目前只需要记住两条：

1. 用 `assign` 赋值的，声明成 `wire`；在 `always` 里赋值的，声明成 `reg`。
2. `input` 端口只能是 wire。

### 片段 D：取出几根线、把几根线拼起来

**[[位选择]]**：从一捆线里抽出一根或几根。

```verilog
wire [4:0] v;   // 假设 v = 5'b01011
v[0]            // 最低位 → 1'b1
v[4]            // 最高位 → 1'b0
v[3:2]          // 第 3、2 位 → 2'b10
```

注意不能写 `v[-1]`。Verilog 不像 Python 那样支持负数下标，越界会报错，或者被接成 0。

**[[拼接运算符]] `{ }`**：把几捆线按顺序并成一捆，**写在最左边的放到最高位**。

```verilog
{2'b10, 3'b011}        // → 5'b10011
{a[0], a[1]}           // a 的第 0 位放高位，第 1 位放低位
```

> [!example] 动手 D（3 分钟）
> 有 `wire [7:0] a;`，请写出一个表达式，把 a 的**高 4 位和低 4 位交换**。例如 `8'hA5` 变成 `8'h5A`。
>
> > [!success]- 参考答案
> > `{a[3:0], a[7:4]}`：先写原来的低 4 位，它就成了新的高 4 位。

## 5. 动手做必做题 1：向量翻转（2 分）

> [!quote] 题目原文（tasks·题目 1）
> 请编写 Verilog 代码，将 8bit 的输入信号按位翻转，并输出到输出端口。

![[媒体库/第01课-拼接运算符-向量翻转题图.png|400]]

**读图顺序**：先看 `in` 的 bit7，顺着箭头会落到 `out` 的 **bit0**；`in` 的 bit0 落到 `out` 的 bit7。所以：

```
out_data[7] = in_data[0]
out_data[6] = in_data[1]
...
out_data[0] = in_data[7]
```

这是**位序颠倒**，不是按位取反 `~in_data`（取反是 0 变 1、1 变 0）。

**框架代码**（题目给的）：

```verilog
module user_module(
    input wire [7:0] in_data,
    output reg [7:0] out_data
);

// 在这里补全逻辑。

endmodule
```

注意 `out_data` 是 **reg**，按片段 C 的规则，它要在 `always` 里赋值。always 的具体含义下一课再讲，这一课先照抄下面这个「模具」：

```verilog
always @(*) begin
    out_data = 你的表达式;
end
```

## 6. 深挖理解

- **核心原理**：向量翻转电路里**一个逻辑门都没有**，只是把 8 根线交叉着接过去。它是最纯粹的「连线」。
- **关键边界**：
  - `{}` 中每一项的位宽都必须是确定的。不能写 `{a, 5}`，因为 5 没有位宽；要写成 `{a, 3'd5}`。
  - 下标不能越界，也不能是负数。
- **常见误区**：
  1. 把翻转写成 `~in_data`（那是按位取反）。
  2. 拼接顺序写反，结果输出和输入一模一样。
  3. 对 `output reg` 用 `assign` 赋值，会报语法错误。
- **为什么重要**：后面的 CPU 实验会大量用到位选择和拼接，例如符号扩展 `{{24{a[7]}}, a[7:0]}`、从指令中截取字段。

## 7. 和已学内容的类比（C 语言）

- **相似点**：语句以 `;` 结尾，注释用 `//` 和 `/* */`，大小写敏感，`a[i]` 的写法看起来像数组下标。
- **差异点**：
  - C 的 `a[i]` 是去内存里找第 i 个元素；Verilog 的 `v[i]` 是**一捆线中的第 i 根线**。
  - C 中的语句按顺序执行；Verilog 中的语句**同时存在**。
  - C 的 int 位宽是固定的；Verilog 中每个信号的位宽都要自己写清楚。
- **迁移边界**：「模块 ≈ 函数」只在讲接口时成立。函数调用完就消失了，模块放进电路后一直在工作。

## 8. 实际应用

- **字节序转换**：网络字节序和主机字节序之间的转换，本质上就是按字节做位置交换，与动手 D 同类。
- **FFT 中的位倒序（bit-reversal）**：快速傅里叶变换需要把下标按位翻转，和本题完全一样。
- **可操作的小任务**：把本题改成 4 位版本，自己写一遍。
