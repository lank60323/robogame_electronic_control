# 端口

## 标准学术解释

- 中文名称：端口（port）：input 输入 / output 输出 / inout 双向
- 学术解释：模块与外界交换信号的接口。外界只能通过端口访问模块，模块内部对外不可见。input 端口必须是 wire 类型；output 端口可以是 wire 或 reg。
- 本课程对应关系：各题框架已经写好端口，名字和位宽都不能改。
- 考试识别方式：问「input 能否声明为 reg」（不能），或者要求补全端口声明。
