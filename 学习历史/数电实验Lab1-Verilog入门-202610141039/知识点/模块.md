# 模块

## 标准学术解释

- 中文名称：模块（module）
- 学术解释：Verilog 的基本设计单元。以 module 开头、endmodule 结束，由模块声明（模块名 + 端口列表）和模块体（内部信号声明、例化、assign、always）组成。
- 本课程对应关系：FPGAOL NEXT 规定每道题的顶层模块名都是 user_module。
- 考试识别方式：题目给出框架，要求「在模块内补全逻辑」；或者问模块体里可以出现哪几类语句。

## 一句话解释

一块有引脚的芯片：外面是端口，里面是电路。

## 正式定义

Verilog 的基本设计单元。以 module 开头、endmodule 结束，由模块声明（模块名 + 端口列表）和模块体（内部信号声明、例化、assign、always）组成。（依据 lab1/verilog1）

## 生活类比

类似 C 函数：端口相当于参数和返回值。不同的是，模块放进电路后会一直存在。（AI补充）

## 常见误区

## 实际应用
