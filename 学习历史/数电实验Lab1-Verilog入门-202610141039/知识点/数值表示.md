# 数值表示

## 标准学术解释

- 中文名称：数值表示：四值逻辑与基数格式常量
- 学术解释：Verilog 的每一位有四种取值：0、1、x（未知）、z（高阻）。整数常量写成 <位宽>'<进制><数值>，进制可以是 b/o/d/h；加 s 表示有符号数。数值超出位宽会被截断。
- 本课程对应关系：选择性必做题的输入 a = 8'b0011_0011 就是这种格式。
- 考试识别方式：进制互相转换；问 x 和 z 的含义；问截断的结果，例如 3'hfff 等于 3'b111。

## 一句话解释

位宽'进制数值，例如 8'hFF。

## 正式定义

Verilog 的每一位有四种取值：0、1、x（未知）、z（高阻）。整数常量写成 <位宽>'<进制><数值>，进制可以是 b/o/d/h；加 s 表示有符号数。数值超出位宽会被截断。（依据 lab1/verilog1）

## 生活类比

类似 C 里的 0x 前缀，但 Verilog 必须带上位宽。（AI补充）

## 常见误区

不写位宽，得到的是至少 32 位的数；把 z 当成 0。

## 实际应用

仿真时看到 x 或 z，说明有信号没接或者没赋值。
