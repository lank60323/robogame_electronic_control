# 硬件描述语言

## 标准学术解释

- 中文名称：硬件描述语言（Hardware Description Language，HDL）
- 学术解释：用形式化文本描述数字电路的结构和行为的语言。综合工具会把它转换成门级网表，再映射为 FPGA 或芯片上的实际电路。和软件编程语言相比，它有两个特点：有时序的概念，语句是并行的。
- 本课程对应关系：Lab1 学的 Verilog 就是一种 HDL；同类语言还有 VHDL、SystemVerilog。
- 考试识别方式：题目问「HDL 与 C 的区别」「为什么说写 Verilog 是在画电路」时考的就是它。

## 一句话解释

用文字画电路，每一行都是一块同时工作的硬件。

## 正式定义

用形式化文本描述数字电路的结构和行为的语言。综合工具会把它转换成门级网表，再映射为 FPGA 或芯片上的实际电路。和软件编程语言相比，它有两个特点：有时序的概念，语句是并行的。（依据 lab1/verilog1）

## 生活类比

C 语言像菜谱，要按顺序执行；HDL 像开关和灯的布线图，所有部分同时工作。（AI补充）

## 常见误区

以为代码会从上往下逐行执行；以为写错的「顺序」可以靠调整语句位置来修。

## 实际应用

FPGA 开发、数字芯片设计；后续的组成原理课会用它写 CPU。
