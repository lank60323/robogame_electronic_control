# 拼接运算符

## 标准学术解释

- 中文名称：拼接运算符（concatenation）{ } 与重复 {n{ }}
- 学术解释：{e1, e2, ..., en} 把各操作数按顺序拼成一个新向量，e1 放在最高位。每个操作数的位宽必须确定。n{e} 把 e 重复 n 次；嵌套在拼接中使用时外面要再加一层大括号，如 {{24{a[7]}}, a[7:0]}。
- 本课程对应关系：必做题 1 用拼接实现位序翻转；选择性必做题中的 g = {a[2:0], b[3:0], {1'b1}}。
- 考试识别方式：求一个拼接表达式的值和位宽。

## 一句话解释

把几捆线按顺序并成一捆，写在左边的成为高位。

## 正式定义

{e1, e2, ..., en} 把各操作数按顺序拼成一个新向量，e1 放在最高位。每个操作数的位宽必须确定。n{e} 把 e 重复 n 次；嵌套在拼接中使用时外面要再加一层大括号，如 {{24{a[7]}}, a[7:0]}。（依据 lab1/verilog1）

## 生活类比

类似字符串拼接 "ab" + "cd"，只不过拼的是二进制位。（AI补充）

## 常见误区

顺序写反；写 {a, 5}，5 没有位宽；重复写成 {24{a[7]}, a}，少了一层大括号。

## 实际应用

符号扩展、字节交换、位倒序。
