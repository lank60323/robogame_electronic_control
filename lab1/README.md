## 设计说明

### 必做 1：向量翻转

题图要求将 `in_data` 按位倒序：`out_data[7] = in_data[0]`，……，`out_data[0] = in_data[7]`。注意这里是**位序翻转**，不是按位取反 `~in_data`。用拼接运算符 `{}` 直接列出 8 位即可，不需要 for 循环。

### 必做 2：最大值问题

1. `assign max = (num1 > num2) ? num1 : num2;` 用条件运算符替代 `if-else`。
2. 用 `if-else` 逐个比较：若 `num1` 不小于另外两个数则输出 `num1`；否则最大值只可能在 `num2`、`num3` 中，再比较一次。
3. 两级 `MAX2` 级联：`max(num1, num2, num3) = MAX2(MAX2(num1, num2), num3)`，中间结果用 `wire max_of_num1_num2` 连接，例化时采用基于端口名称的关联。

### 必做 3：1 的个数

`out_count = in_data[0] + in_data[1] + in_data[2];`。Verilog 中表达式位宽取左右两侧的最大值，左侧 `out_count` 为 2 bit，因此加法在 2 bit 下进行，最大值 3 不会溢出。

### 选择性必做 2：Verilog 运算符

`a = 8'b0011_0011`，`b = 8'b1111_0000`（均为无符号数）：

| 信号 | 表达式 | 结果 | 说明 |
| --- | --- | --- | --- |
| c | `a & b` | `8'b0011_0000` | 按位与 |
| d | `a \|\| b` | `8'b0000_0001` | 逻辑或：两者均非零，结果为 1 bit 的 1，零扩展到 8 bit |
| e | `a ^ b` | `8'b1100_0011` | 按位异或 |
| f | `~a` | `8'b1100_1100` | 按位取反 |
| g | `{a[2:0], b[3:0], {1'b1}}` | `8'b0110_0001` | 拼接：`011` + `0000` + `1` |
| h | `b >>> 3` | `8'b0001_1110` | `b` 为无符号数，算术右移高位补 0 |
| i | `&b` | `8'b0000_0000` | 归约与：`b` 中有 0，结果为 0 |
| j | `(a > b) ? a : b` | `8'b1111_0000` | 51 < 240，取 `b` |
| k | `a - b` | `8'b0100_0011` | 51 − 240 = −189，模 256 得 67 |
| l | `!a` | `8'b0000_0000` | 逻辑非：`a` 非零，结果为 0 |

以上结果已通过 `tb/tb_operators.v` 仿真验证。

### 选做 1：Verilog 数组

```verilog
reg [31:0] reg_array [0:15];   // 16 个位宽为 32 的 reg 型变量
```

`[31:0]` 是每个元素的位宽，`[0:15]` 是数组深度。写操作在 `clk` 上升沿进行，`rst` 高电平同步复位并优先于写使能；读操作为 `assign rdata = reg_array[raddr];` 组合读出。复位时用 for 循环清零 16 个寄存器，循环在综合时展开为 16 份并行的清零逻辑，不会产生组合环。

### 选做 2：带参数例化

`MUX2` 用参数 `WIDTH` 决定位宽，顶层通过 `MUX2 #(.WIDTH (8)) mux2_8bit (...)` 例化为 8 bit 选择器。

`#` 与 `defparam` 的区别：

- **`#(...)` 参数传递**：在例化语句中直接给出参数值，参数与例化写在一起，作用范围仅限于这一个实例，可读性好，是可综合代码中推荐的写法。
- **`defparam`**：用层次化路径在任意位置覆盖参数，例如 `defparam top.mux2_8bit.WIDTH = 8;`。它可以在不修改例化语句的情况下修改深层实例的参数，常见于旧代码或测试平台中批量修改参数；但参数值与例化分离，不易追踪，部分综合工具支持不好，IEEE 1364-2005 起已不推荐使用。
